Sellers (auto-approve & contact)

Sellers marked trusted have their new submissions and edits auto-approved — no manual review, the catalog rebuilds automatically (debounced ~2 min). Use the ✉ Email link on any row to message that seller directly.

Rotate seller link

Use only when a seller reports their private link was leaked. Issues a new link and emails it to them; the old link stops working.

Expiring listings

Listings auto-demote to "Not Renewed" after 60 days without seller activity. Use "Refresh now" on a seller's row to extend all their renewable listings (useful when a seller is on vacation). The list shows sellers with the most-urgent listings first.

Update catalog

Manually trigger a GitHub workflow rebuild of canvascircle.art — useful if you want a fresh deploy without changing any listing. New listings normally trigger a rebuild automatically on approval; this is the manual "go" button.
